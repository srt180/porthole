# Porthole 需求文档

## 1. 项目概述

`Porthole` 是一个面向开发者与运维人员的本机端口巡检 TUI 工具，用于在终端中快速查看当前机器上正在监听的 TCP / UDP 端口，并进一步查看对应进程、进程位置、工作目录等关键信息。

项目首版目标是提供一个“开箱即用、零外部 Python 依赖、对本机状态足够透明”的 MVP，优先覆盖日常开发排查场景。

## 2. 背景与问题

本机端口排查通常依赖以下方式：

- `lsof` / `netstat` / `ss` 等命令逐次查询
- 图形化系统监控工具，但端口维度信息不集中
- 手工结合 `ps`、`pwdx`、`which` 等命令补齐进程信息

这些方式的问题是：

- 信息分散，需要多次切换命令
- 不方便按端口和进程快速浏览
- 进程位置、工作目录等上下文获取成本高
- 在排查“哪个程序占用了端口”时效率不高

## 3. 目标

### 3.1 产品目标

- 在单个终端界面中展示本机监听端口与进程信息
- 降低“端口被谁占用”“这个监听来自哪个程序”的排查成本
- 提供足够清晰的详情视图，帮助用户定位可执行文件位置

### 3.2 首版技术目标

- 基于 Python 标准库实现
- 不依赖第三方 Python 包
- 通过系统命令采集数据，首版采用 `lsof`
- 优先支持 macOS，兼容支持已安装 `lsof` 的 Linux 环境

## 4. 目标用户

- 本地开发者
- 需要排查端口占用的测试/运维人员
- 希望在 SSH / 终端环境下完成排查的用户

## 5. 使用场景

- 启动服务失败后，快速确认目标端口已被哪个进程占用
- 查看本机当前有哪些 TCP/UDP 监听
- 确认某个监听对应的进程路径是否符合预期
- 快速查看进程工作目录，辅助定位具体项目实例

## 6. MVP 功能范围

### 6.1 端口列表

系统应支持展示以下字段：

- 协议：`TCP` / `UDP`
- IP 版本：`IPv4` / `IPv6`
- 监听地址
- 监听端口
- 完整端点表示，如 `127.0.0.1:8080`
- 进程名
- PID
- 用户名
- 文件描述符（FD）
- TCP 状态（首版主要关注 `LISTEN`）

### 6.2 详情面板

系统应支持查看当前选中记录的详情，包括：

- 进程名
- PID
- 用户名
- 协议与 IP 版本
- 监听地址与端口
- FD
- TCP 状态
- 可执行文件路径
- 当前工作目录

### 6.3 TUI 交互

首版支持以下交互：

- 上下方向键移动选中项
- `j` / `k` 移动选中项
- `a` 查看全部协议
- `t` 仅查看 TCP
- `u` 仅查看 UDP
- `r` 立即刷新
- `q` 退出程序

### 6.4 刷新策略

- 启动时自动采集一次
- 支持固定间隔自动刷新
- 用户可手动触发刷新

### 6.5 异常处理

- 当系统命令不存在时，界面需要明确提示
- 当采集失败时，界面不能崩溃，应保留错误状态
- 当进程在刷新过程中退出时，详情面板应优雅降级为“不可用”

## 7. 非目标

以下内容不在首版范围内：

- 杀掉进程 / 结束监听
- 修改防火墙规则
- 查看远程主机端口
- Windows 原生支持
- 容器 / 虚拟机命名空间内的独立端口视图
- 搜索、排序自定义、导出报表

## 8. 交互草图

界面采用双栏布局：

- 左侧：端口列表
- 右侧：当前选中项详情
- 顶部：标题、当前过滤条件、刷新时间
- 底部：快捷键帮助与状态信息

## 9. 数据来源与约束

### 9.1 数据来源

首版通过 `lsof` 采集：

- TCP 监听：`lsof -nP -iTCP -sTCP:LISTEN`
- UDP 监听：`lsof -nP -iUDP`
- 进程详情：`lsof -a -p <pid> -d cwd,txt`

### 9.2 约束与风险

- 未提升权限时，部分系统进程信息可能不可见
- 不同系统版本下 `lsof` 输出细节可能略有差异
- 端口与进程状态是瞬时数据，刷新间隔内可能变化

## 10. 方案取舍

首版优先采用“零 Python 三方依赖 + 系统命令采集”的方案，原因如下：

- 当前目录为空，先交付可运行 MVP 的性价比最高
- 减少依赖安装门槛，便于直接运行
- `lsof` 已能满足端口、协议、PID、路径、工作目录等核心需求

后续如需增强跨平台能力，可引入：

- 平台抽象层
- Windows 适配器
- 更丰富的进程元数据采集方式

## 11. 验收标准

满足以下条件视为首版可用：

- 程序可在终端成功启动 TUI
- 可以看到 TCP / UDP 监听列表
- 可以切换协议过滤
- 可以上下移动选中项
- 右侧可以展示所选监听对应的 PID、路径与工作目录
- 刷新失败时不会退出，并能提示原因
